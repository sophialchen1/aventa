# Aventa Website

Source code for **aventawindows.com** (Aventa premium laminated wood windows and doors).

Maintained by Sophia Chen. Inherited from a third-party developer in 2026.

---

## What this is

| Layer | Technology | What it actually does |
|---|---|---|
| Backend | Laravel 12 (PHP) | Thin shell. Serves one Blade view and boots the app. |
| Frontend | Vue 3 + Vite | The real site. Runs as a single-page app (SPA). |
| Styling | Tailwind CSS 4 | Utility classes in the Vue components. |
| Languages | vue-i18n | Bilingual ES / EN. All copy lives in JSON locale files. |

There is **no CMS and no admin panel**. Every content change is a code change.

## Where things live

```
resources/js/src/locales/es.json   <- Spanish copy (all site text)
resources/js/src/locales/en.json   <- English copy (must mirror es.json)
resources/js/                      <- Vue components, pages, router
resources/views/                   <- the single Blade view Laravel serves
public/                            <- static assets + build output
public/build/                      <- generated by `npm run build`, do not edit
routes/web.php                     <- Laravel routes (minimal, SPA catch-all)
```

## Common tasks

**Change text on the site** -> edit `resources/js/src/locales/es.json` and the
matching key in `en.json`. Never edit only one language.

**Change layout or add a section** -> edit the Vue component under `resources/js/`.

**Publish changes** -> see [DEPLOY.md](DEPLOY.md).

|---|---|

nothing on the live site.** The files the public sees are in `public_html/`.
